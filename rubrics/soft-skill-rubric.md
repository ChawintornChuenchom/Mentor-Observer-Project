# Soft Skill Rubric — ตารางให้คะแนนส่วนกลาง

> ประเมินครั้งเดียวตอนจบ session จาก transcript ทั้งหมด
> คะแนนเต็ม 3 — ได้ 3 = ผ่าน
> ผลลัพธ์แสดงเป็นตัวเลข + ประโยคสรุปเป็นภาษาพูด

---

## 4 มิติที่ประเมิน

| มิติ | ID | วัดอะไร |
|---|---|---|
| **Curiosity** | `curiosity` | ตั้งคำถามกลับเอง สำรวจนอกเหนือสิ่งที่ถูกถาม |
| **Persistence** | `persistence` | ไม่ยอมแพ้เมื่อติดขัด พยายามต่อจนกว่าจะได้คำตอบ |
| **Critical Thinking** | `critical_thinking` | วิเคราะห์ โต้แย้ง มองหลายมุม ไม่รับข้อมูลโดยไม่คิด |
| **Learning Speed** | `learning_speed` | เรียนรู้เร็วแค่ไหน วัดจากจำนวน message ก่อนเข้าใจ และการเชื่อมโยงเนื้อหาใหม่กับสิ่งที่รู้อยู่แล้ว |

## เกณฑ์คะแนน (ใช้กับทุกมิติ)

| คะแนน | ความหมาย |
|---|---|
| **3** | ผ่าน — แสดงพฤติกรรมชัดเจน สม่ำเสมอ |
| **2** | ใกล้ผ่าน — แสดงออกบ้างแต่ยังไม่สม่ำเสมอ |
| **1** | ยังไม่ผ่าน — แสดงออกน้อยมาก หรือต้องการการกระตุ้นมาก |
| **0** | แสดงพฤติกรรมตรงข้ามชัดเจน |
| **null** | ยังไม่มีหลักฐานเพียงพอใน session นี้ |

## Curiosity

| คะแนน | พฤติกรรมที่สังเกตได้ |
|---|---|
| **3** | ตั้งคำถามกลับเองโดยไม่มีใครชี้นำ หรือขยายออกนอกขอบเขตที่ Mentor ถาม |
| **2** | ตั้งคำถามได้เมื่อ Mentor ชวนให้ถาม ไม่ได้ถามเอง |
| **1** | แทบไม่ตั้งคำถามเลย แม้จะถูกชวน |
| **0** | ปฏิเสธที่จะสำรวจหรือแสดงความไม่สนใจชัดเจน |
| **null** | session สั้นเกินไป ยังไม่มีโอกาสแสดง |

ตัวอย่างประโยคสรุป:
- 3 → "มีความอยากรู้สูง ตั้งคำถามกลับเองหลายครั้งและขยายออกนอกเนื้อหา"
- 2 → "ถามได้เมื่อถูกกระตุ้น แต่ยังไม่ริเริ่มเอง"
- 1 → "ไม่ค่อยสงสัยหรือตั้งคำถาม ต้องการการกระตุ้นมาก"
- 0 → "แสดงความไม่สนใจ ปฏิเสธที่จะสำรวจเนื้อหา"

## Persistence

| คะแนน | พฤติกรรมที่สังเกตได้ |
|---|---|
| **3** | ไม่ยอมแพ้เมื่อเจอคำถามยาก พยายามต่อจนได้คำตอบ บางครั้งแก้ไขคำตอบเองโดยไม่รอ Mentor |
| **2** | พยายามต่อเมื่อ Mentor ให้กำลังใจ แต่ไม่ริเริ่มเอง |
| **1** | ท้อเร็ว ต้องการการกระตุ้นหลายรอบก่อนจะลองต่อ |
| **0** | ยอมแพ้ทันทีเมื่อเจอปัญหา ขอให้บอกคำตอบตรงๆ ซ้ำๆ |
| **null** | ตอบถูกตลอด ยังไม่เจอสถานการณ์ที่ต้องใช้ความอดทน |

ตัวอย่างประโยคสรุป:
- 3 → "มีความอดทนสูง ไม่ยอมแพ้แม้จะติดขัด พยายามหาคำตอบด้วยตัวเอง"
- 2 → "พยายามต่อเมื่อได้รับกำลังใจ แต่ยังพึ่งพา Mentor อยู่บ้าง"
- 1 → "ท้อได้ง่าย ต้องการการกระตุ้นบ่อยครั้ง"
- 0 → "ยอมแพ้เร็วมาก มักขอให้บอกคำตอบโดยไม่พยายาม"

## Critical Thinking

| คะแนน | พฤติกรรมที่สังเกตได้ |
|---|---|
| **3** | อธิบายเหตุผลได้เอง โต้แย้งหรือตั้งคำถามเชิงวิเคราะห์โดยไม่มีใครชี้นำ |
| **2** | อธิบายเหตุผลได้เมื่อ Mentor ถามว่า "ทำไม" ไม่ได้อธิบายเองก่อน |
| **1** | ตอบถูก/ผิดโดยไม่มีเหตุผล ต้องถูกถามซ้ำหลายรอบ |
| **0** | รับข้อมูลทุกอย่างโดยไม่ตั้งคำถาม หรือมีความเข้าใจผิดและยึดถืออยู่แม้จะถูกชี้ |
| **null** | ยังไม่มีสถานการณ์ที่เปิดโอกาสให้แสดง |

ตัวอย่างประโยคสรุป:
- 3 → "มีมุมมองความคิดที่ลึก อธิบายเหตุผลได้เองและตั้งคำถามเชิงวิเคราะห์"
- 2 → "อธิบายเหตุผลได้เมื่อถูกถาม แต่ยังไม่ริเริ่มวิเคราะห์เอง"
- 1 → "มักตอบโดยไม่มีเหตุผล ต้องการคำถามนำหลายรอบ"
- 0 → "รับข้อมูลโดยไม่ตั้งคำถาม หรือยึดถือความเข้าใจผิดแม้จะถูกชี้"

## Learning Speed

> วัดจาก 2 อย่างประกอบกัน:
> 1. จำนวน message ก่อนที่นักเรียนจะแสดงความเข้าใจแต่ละจุด — น้อย = เรียนเร็ว
> 2. การเชื่อมโยงเนื้อหาใหม่กับสิ่งที่รู้อยู่แล้วได้เองโดยไม่ต้องให้ Mentor ชี้

| คะแนน | พฤติกรรมที่สังเกตได้ |
|---|---|
| **3** | เข้าใจแต่ละจุดได้เร็ว ต้องการ message น้อย และเชื่อมโยงเนื้อหาใหม่กับความรู้เดิมได้เอง |
| **2** | เรียนรู้ได้ในระยะเวลาปานกลาง เชื่อมโยงได้บ้างเมื่อ Mentor ชี้แนะ |
| **1** | ต้องใช้ message หลายรอบก่อนเข้าใจแต่ละจุด เชื่อมโยงเนื้อหาเองได้น้อย |
| **0** | แทบไม่แสดงความเข้าใจออกมาเลยตลอด session |
| **null** | session สั้นเกินไป ยังสรุปไม่ได้ |

ตัวอย่างประโยคสรุป:
- 3 → "เรียนรู้ได้เร็ว เชื่อมโยงความรู้เก่ากับใหม่ได้เองโดยไม่ต้องให้ชี้"
- 2 → "เรียนรู้ได้ในระยะเวลาปานกลาง ต้องการคำแนะนำบ้างในการเชื่อมโยงเนื้อหา"
- 1 → "ใช้เวลานานกว่าจะเข้าใจแต่ละจุด ต้องการความช่วยเหลือค่อนข้างมาก"
- 0 → "ไม่แสดงความเข้าใจออกมาอย่างมีนัยสำคัญตลอด session"

## กฎสำหรับ Observer

- ประเมินจาก **transcript ทั้งหมด** ไม่ใช่แค่ช่วงใดช่วงหนึ่ง
- คะแนนสะท้อน **จุดที่ดีที่สุดที่แสดงออกมา** ไม่ใช่ค่าเฉลี่ย
- **null ≠ 0** — null คือยังไม่มีโอกาสแสดง, 0 คือมีโอกาสแล้วแต่แสดงพฤติกรรมตรงข้าม
- ห้ามให้คะแนนจากคำตอบที่ echo คำพูดของ Mentor
- ประโยคสรุปต้องเป็นภาษาพูดธรรมชาติ ไม่ใช่ศัพท์วิชาการ
