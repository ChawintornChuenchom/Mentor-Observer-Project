# ดัชนี Soft Skill (S01–S12) — ใช้สำหรับเลือกสกิลเท่านั้น

แต่ละสกิลมี 2 ประโยค: สกิลนี้คืออะไร · ประเมินได้เมื่อวัตถุประสงค์ของบทให้นักเรียนทำอะไร
ข้อความในวงเล็บคือสิ่งที่ "ไม่นับ" — ถ้า sub_lo มีแค่สิ่งนั้น ห้ามเลือก
rubric และรายละเอียดอยู่ในไฟล์ S01–S12

## รายการสกิล
- **S01 การคิดเชิงวิพากษ์** — ประเมินหลักฐานและข้อโต้แย้งอย่างมีเหตุผลก่อนลงข้อสรุป · ประเมินได้เมื่อ sub_lo ให้นักเรียนวิเคราะห์ เปรียบเทียบ หรือชั่งเหตุผล/หลักฐานหลายด้าน จนวิจารณ์ข้อสรุปที่ให้เหตุผลไม่ครบได้ (การอธิบายเหตุผลตามที่บทเรียนสอนไว้อย่างเดียวไม่นับ)
- **S02 การแก้ปัญหา** — นิยามปัญหา วางแนวทาง ลงมือแก้ และประเมินผลอย่างเป็นระบบ · ประเมินได้เมื่อ sub_lo ให้นักเรียนแก้โจทย์หรือกรณีที่มีหลายขั้นหรือหลายทางเลือก โดยยังไม่บอกวิธีแก้ (การทำตามขั้นตอนที่สอนจนได้คำตอบถูกไม่นับ)
- **S03 การสื่อสารด้วยการเขียน** — ถ่ายทอดความคิดเป็นข้อความที่ชัดเจน มีลำดับ และเหมาะกับผู้รับสาร · ประเมินได้เมื่อ sub_lo ให้นักเรียนเขียนอธิบายยาว หรือเขียนถึงผู้รับที่กำหนด (การตอบคำถามเนื้อหาสั้นๆ ไม่นับ)
- **S04 การตั้งคำถามและความใฝ่รู้** — แสวงหาความเข้าใจที่ลึกขึ้นผ่านการตั้งคำถามที่มีคุณภาพ · ประเมินได้เมื่อ sub_lo มีเรื่องที่ถามต่อได้ว่า "ทำไม/อย่างไร" หรือเชื่อมกับโลกจริงได้ และกิจกรรมเปิดช่องให้นักเรียนเป็นฝ่ายถาม (คำถามขอเฉลยไม่นับ)
- **S05 อภิปัญญาและการสะท้อนตนเอง** — รู้ว่าตนรู้หรือไม่รู้อะไร และปรับวิธีเรียนของตนเอง · ประเมินได้เมื่อ sub_lo มีจุดที่เข้าใจผิดบ่อย หรือกิจกรรมให้นักเรียนประเมินความเข้าใจของตนเอง (การตอบว่า "เข้าใจแล้ว" โดยไม่มีหลักฐานไม่นับ)
- **S06 การรู้เท่าทันสารสนเทศ** — ค้นหา ประเมินความน่าเชื่อถือ และใช้สารสนเทศอย่างเหมาะสม รวมถึงข้อมูลจาก AI · ประเมินได้เมื่อ sub_lo ให้นักเรียนเทียบ ตรวจสอบ หรือเลือกใช้แหล่งข้อมูล (การจำข้อเท็จจริงจากบทเรียนไม่นับ)
- **S07 ความคิดสร้างสรรค์** — สร้างแนวคิดหรือวิธีการใหม่ที่มีคุณค่าและเป็นไปได้ · ประเมินได้เมื่อ sub_lo เป็นโจทย์ปลายเปิด การออกแบบ หรือการเสนอทางเลือกที่มีหลายคำตอบ (การเห็นด้วยกับแนวคิดที่ Mentor เสนอไม่นับ)
- **S08 การใช้เหตุผลเชิงจริยธรรม** — ระบุประเด็นจริยธรรม วิเคราะห์หลายมุม และตัดสินใจอย่างมีเหตุผล · ประเมินได้เมื่อ sub_lo มีสถานการณ์ที่คุณค่าหรือหลักการขัดกันให้นักเรียนตัดสินใจ (การแสดงจุดยืนทางการเมือง ศาสนา หรือความเชื่อไม่นับ)
- **S09 ความเข้าอกเข้าใจ** — เข้าใจความคิด ความรู้สึก และบริบทของผู้อื่น แล้วตอบสนองอย่างเหมาะสม · ประเมินได้เมื่อ sub_lo ให้นักเรียนมองจากมุมของบุคคลอื่น เช่น ผู้ป่วย ลูกค้า ชุมชน หรือสวมบทบาทสื่อสารกับบุคคลนั้น (คำสุภาพตามแบบฟอร์มไม่นับ)
- **S10 การเรียนรู้เชิงบูรณาการ** — เชื่อมความรู้ข้ามวิชาและประสบการณ์ เพื่อนำไปใช้ในสถานการณ์ใหม่ · ประเมินได้เมื่อ sub_lo ให้นักเรียนเชื่อมกับวิชาอื่น ประสบการณ์ตนเอง หรือใช้ความรู้กับสถานการณ์นอกบท (การเชื่อมโยงเนื้อหาภายในบทเดียวกันไม่นับ)
- **S11 การปรับตัวและการรับฟีดแบ็ก** — เปิดรับคำแนะนำ นำไปปรับปรุง และคงความพยายามเมื่อเจอความยาก · ประเมินได้เมื่อ sub_lo มีคำตอบหรืองานที่แก้ได้หลายรอบหลังได้ฟีดแบ็ก (การตอบ "ครับ/ค่ะ" โดยไม่แก้ไม่นับ)
- **S12 การใช้เหตุผลเชิงปริมาณ** — ใช้ ตีความ และสื่อสารข้อมูลเชิงตัวเลขเพื่อสนับสนุนการตัดสินใจ · ประเมินได้เมื่อ sub_lo ให้นักเรียนใช้หรือตีความตัวเลขประกอบการตัดสินใจ (การคำนวณตามโจทย์ที่เป็น sub_lo อยู่แล้ว หรือการจำตัวเลขไม่นับ)

## คู่ที่มักสับสน
- S01 vs S04: วิจารณ์ข้อสรุปหรือหลักฐานที่มีอยู่ → S01 / นักเรียนเป็นฝ่ายตั้งคำถามเพื่อเข้าใจเพิ่ม → S04
- S01 vs S06: ประเมินเหตุผลในข้อโต้แย้ง → S01 / ประเมินแหล่งที่มาของข้อมูล → S06
- S01 vs S08: ชั่งหลักฐานเชิงข้อเท็จจริง → S01 / ชั่งหลักการเชิงคุณค่า → S08
- S01 vs S10: ตรวจว่าข้อโต้แย้งถูกต้องไหม → S01 / นำความรู้ไปเชื่อมหรือใช้นอกบท → S10
- S02 vs S07: เป้าหมายชัด ต้องหาวิธีไปถึง → S02 / มีคำตอบที่ดีได้หลายแบบ ต้องสร้างใหม่ → S07
- S02 vs S12: แก้ปัญหาหลายขั้น → S02 / ใช้ตัวเลขประกอบการตัดสินใจ → S12
- S05 vs S11: นักเรียนตรวจความเข้าใจของตนเอง → S05 / นักเรียนตอบสนองต่อฟีดแบ็กจาก Mentor → S11
- S03 vs hard skill: sub_lo ที่ให้ "อธิบาย" เนื้อหา ความถูกต้องเป็นของ sub_lo · เลือก S03 เฉพาะเมื่อกำหนดผู้รับสารหรือรูปแบบงานเขียน

## วิธีเลือก
1. อ่าน main_lo และ sub_los (statement, type, mentor_activity, observable_evidence) — ไม่ใช่ชื่อวิชาหรือความรู้ทั่วไปเกี่ยวกับหัวข้อ
2. สกิลถูกเลือกได้เมื่อมี sub_lo อย่างน้อย 1 ข้อตรงกับประโยค "ประเมินได้เมื่อ" และไม่ใช่สิ่งที่อยู่ในวงเล็บ
3. ต้องปรับ mentor_activity ของ sub_lo นั้นให้เปิดโอกาสแสดงสกิลได้ โดยกิจกรรมยังทำให้ sub_lo บรรลุ และไม่ใช้ข้อมูลนอกบทเรียน — ถ้าทำไม่ได้ ห้ามเลือก
4. เลือก 0–5 สกิล ห้ามเลือกเพื่อให้ครบจำนวน
5. สกิลที่ไม่เลือก ระบุเหตุผล 1 ประโยค
